# Cellulose III-I unit cell

`structure.pdb` is a geometry-only diagnostic structure generated from the
published monoclinic P2_1 fractional coordinates retained by
Cellulose-Builder. It contains one chain and two anhydroglucose residues (42
atoms), with the second residue generated by the P2_1 screw operation.

```bash
uv run cellulose-forge build \
  --allomorph III-I \
  --shape unit-cell \
  --output examples/iii_i_unit_cell/structure.pdb
```

The coordinates have not been energy-minimized and this PDB contains no
force-field topology.
