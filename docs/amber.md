# Native Amber output

CelluloseForge can write complete multi-chain GLYCAM systems in native Amber
format for finite cellulose chains:

```bash
cellulose-forge build \
  --allomorph I-beta --shape fibril --fibril-model 18-chain \
  --degree-polymerization 6 --chain-boundary finite \
  --vacuum 30 --padding-longitudinal 20 \
  --force-field glycam --md-engine gromacs --md-engine amber \
  --output ibeta_18chain_glycam
```

The Amber outputs are `structure.prmtop` and `structure.inpcrd`. They describe
the complete system; the temporary one-chain topology generated by `tleap` is
replicated with ParmEd and assigned the same mapped crystallographic
coordinates and box used by the GROMACS output. CelluloseForge reloads the
written files and records atom count, residue count, total charge, and box in
`build_report.json`.

## Boundary restriction

Native Amber output currently supports finite chains only. Amber does not
apply minimum-image treatment to a bonded interaction crossing the periodic
chain-direction boundary. A covalently periodic cellulose chain would
therefore contain a box-length O4--C1 bonded term even though the corresponding
GROMACS topology is valid. CelluloseForge refuses this unsafe combination.
Use GROMACS or OpenMM output for covalently periodic chains.

## Development validation

The implementation was checked with AmberTools23/ParmEd and GROMACS 2024.2.
A finite I-beta 18-chain, DP6 fibril written for both MD engines:

- reloaded as a neutral 2,322-atom Amber system containing 108 AGUs and 18
  terminal `ROH` cap records (126 Amber topology residue records in total);
- passed `gmx grompp` with no warnings using the finite PME minimization input;
- completed a 20-step `sander` minimization without non-finite energies;
- retained normal final bonded contributions (bond energy 163.48 kcal/mol).

The same writer was also checked on a finite DP2 fibril and preserved the
triclinic I-beta unit-cell box when exercised during development. These are
format and topology smoke tests, not material-property validation.
