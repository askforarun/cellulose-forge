# Governance

CelluloseForge is currently maintained by the project owner, who has final responsibility for releases, scientific scope, and repository administration.

Design decisions that affect crystallographic interpretation, force-field behavior, file formats, or compatibility are documented in `docs/decisions/`. Contributions are reviewed for scientific correctness, tests, provenance, and maintainability. As the contributor community grows, this document will be revised to describe additional maintainer roles and a transparent process for appointing them.

Project participation is governed by the repository's `CODE_OF_CONDUCT.md`.
