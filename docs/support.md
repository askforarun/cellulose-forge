# Support

Use [GitHub Issues](https://github.com/askforarun/cellulose-forge/issues) for bug reports, feature requests, installation problems, and scientific questions about CelluloseForge.

Before opening an issue, search existing reports and include the CelluloseForge version, operating system, Python version, complete command, relevant input files, and the full error output. For incorrect structures or topologies, also identify the allomorph, system dimensions, chain-boundary mode, and force-field version.

Please do not report security-sensitive information in a public issue. Until a private security-reporting channel is published, contact the repository owner through their GitHub profile.
