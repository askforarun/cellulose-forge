# External reference implementations

CelluloseForge does not vendor or import third-party builder distributions.
The following works informed the scientific specification and are used for
independent comparison and provenance:

- Gomes, T. C. F.; Skaf, M. S. *Cellulose-Builder: A toolkit for building
  crystalline structures of cellulose*. Journal of Computational Chemistry
  **33**, 1338–1346 (2012). DOI: [10.1002/jcc.22959](https://doi.org/10.1002/jcc.22959).
- Danne, R. et al. *doGlycans—Tools for Preparing Carbohydrate Structures for
  Atomistic Simulations of Glycoproteins, Glycolipids, and Carbohydrate
  Polymers for GROMACS*. Journal of Chemical Information and Modeling **57**,
  2401–2406 (2017). DOI:
  [10.1021/acs.jcim.7b00237](https://doi.org/10.1021/acs.jcim.7b00237).

Crystallographic definitions distributed with CelluloseForge are structured
project data with source citations and DOI metadata. Compact independently
generated test fixtures are retained under `examples/` and `validation/`.
